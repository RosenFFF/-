# 丝路智审 · 前端设计方向（M0）

> 匿名文档：不写学校/姓名。表面类型：**app/product**（合规审查工作台，不是营销落地页）。
> 方法：[frontend-visual-direction](sand-workflow:frontend-visual-direction) + [anti-ai-ui](sand-workflow:anti-ai-ui)。

## 0. 题材锚定

| 项 | 内容 |
| --- | --- |
| 产品 | 丝路智审：跨境贸易单证 AI 合规审查 |
| 用户 | 外贸合规员 / 单证员（现场 10 分钟演示的主操作者） |
| 主任务 | 上传单证 → 核对识别字段 → 读风险分级与条款引用 → 追问 → 展示安全审计 |
| verncular | 报关、原产地、禁限运、条款号、风险等级、脱敏、审计轨迹 — 像验单台，不像「AI SaaS 官网」 |

**品类反射测试**：遮住产品名后，应仍读成「单证/合规工具」，而不是任意紫色渐变 AI 创业页。若像后者，方向失败。

## 1. ONE 概念：验单台（Desk Review）

一句话：海关验单台气质 — **左导航 + 中央作业面（左原件 / 右结构化结果）**，风险色是唯一强记忆点，其余克制。

```
┌────────┬──────────────────────────────────────────────┐
│ Brand  │ 案件标题 · 单证类型 · 状态芯片               │
│ 导航   ├───────────────────┬──────────────────────────┤
│ 案件   │                   │ 字段表 / 风险列表         │
│ 上传   │   单证原件预览     │ 条款引用抽屉              │
│ 审查   │   （可缩放）       │ 追问输入（贴底）          │
│ 审计   │                   │                          │
└────────┴───────────────────┴──────────────────────────┘
```

原则（只大胆一处）：
1. **风险分级色带**做记忆点（高/中/低/通过），其余界面近中性墨色。
2. 信息密度优先于装饰；分隔靠层级与 1px 线，不靠大阴影卡堆。
3. 文案像工具：动词明确（「上传单证」「开始审查」「导出报告」），禁止 elevate/unlock/AI-powered。
4. 动效只服务操作反馈（按压、面板开合），禁止滚动 fade-up 与装饰渐变。

## 2. Design tokens

### 2.1 颜色（浅色默认；演示用浅色，审计页可局部深色条）

| Token | Hex | 用途 |
| --- | --- | --- |
| `--ink` | `#1A1C1E` | 主文字 |
| `--ink-secondary` | `#3F434A` | 次要文字（对比 ≥4.5:1） |
| `--ink-muted` | `#5C6370` | 辅助说明（仅大字号/非长正文） |
| `--paper` | `#FFFFFF` | 主表面 |
| `--canvas` | `#EEF0F3` | 应用底（冷灰，非奶油） |
| `--line` | `#D5D9E0` | 分割线 / 表框 |
| `--brand` | `#0F5C5C` | 主操作 / 选中导航（青绿墨，非紫蓝） |
| `--brand-hover` | `#0A4848` | |
| `--brand-subtle` | `#E4F2F2` | 选中底 |
| `--risk-high` | `#B42318` | 高风险 |
| `--risk-med` | `#B54708` | 中风险 |
| `--risk-low` | `#875A00` | 低风险提示 |
| `--risk-pass` | `#087443` | 通过 |
| `--focus` | `#0F5C5C` | `:focus-visible` 环（2px） |

禁止：紫/靛默认主色、紫→蓝渐变、奶油 `#faf8f4`/`#F4F1EA`、mesh/aurora/blob、gradient text、玻璃拟态默认。

### 2.2 字体

| 角色 | 字体 | 说明 |
| --- | --- | --- |
| UI / 中文 | `Noto Sans SC` | 界面与表格 |
| UI Latin | `IBM Plex Sans` | 与 Noto 混排；**不用** Inter / Geist |
| 条款引用 | `Noto Serif SC` | 法规摘录，与 UI 字形成对比 |
| 等宽 | `IBM Plex Mono` | 单证号、哈希、请求 ID、审计字段 |

字阶（rem，根 16px）：

| Token | Size / Line / Weight |
| --- | --- |
| `display` | 28 / 36 / 600（页面标题，少用） |
| `title` | 20 / 28 / 600 |
| `body` | 15 / 24 / 400 |
| `body-sm` | 13 / 20 / 400 |
| `label` | 12 / 16 / 500（表头、字段名；sentence case，非全大写 tracking） |
| `mono` | 12 / 18 / 400 |

大标题字距约 `-0.01em`；正文字距 0。数字（金额、风险计数）用 `tabular-nums`。

### 2.3 空间与形状

| Token | 值 |
| --- | --- |
| 间距阶 | 4 / 8 / 12 / 16 / 24 / 32 / 48 |
| 圆角 | 控件 `4px`；面板 `6px`；**禁止**全站 `rounded-2xl` |
| 阴影 | 仅浮层：`0 8px 24px rgba(26,28,30,0.12)`；卡片默认无阴影，用 `--line` |
| 布局 | 左栏固定 220px；作业区最小宽 960px；内容区左右对齐同一 gutter 24px |

### 2.4 动效

| 场景 | 时长 / 曲线 |
| --- | --- |
| 按钮 `:active` | `transform scale(0.98)` 120ms ease-out |
| 抽屉 / Dialog | 200–280ms ease-out；从触发侧或底部 |
| 路由切换 | 无装饰过渡（高频） |
| 禁止 | 每块 fade-up、统一 `hover:scale-105`、无意义 parallax |

尊重 `prefers-reduced-motion`：保留透明度/颜色，去掉位移。

### 2.5 图标

统一 **Phosphor**（或全站 Lucide，二选一不可混）。线性 1.5–2px，与正文同色；风险行可用实心小圆点色标，不用 emoji / ✨。

## 3. 页面信息架构

路由建议（实现时对齐 `docs/api.yaml`）：

| 路由 | 名称 | 目的 | 关键模块 |
| --- | --- | --- | --- |
| `/login` | 登录 | RBAC 入口 | 账号、角色提示、错误态 |
| `/cases` | 案件列表 | 选案 / 新建 | 表格、状态、筛选 |
| `/cases/new` | 上传单证 | 建案并上传 | 拖放区、类型选择、脱敏声明 |
| `/cases/:id/extract` | 识别对照 | OCR 结果人工核对 | 原件预览 + 字段表双栏、置信度、改字段 |
| `/cases/:id/report` | 审查报告 | 风险分级 + 条款引用 | 摘要条、风险列表、引用侧栏、导出 |
| `/cases/:id/ask` | 追问 | 针对本报告多语种问答 | 消息流、引用气泡、限流/安全提示 |
| `/audit` | 安全审计看板 | 演示抽测点 | 登录事件、模型调用、脱敏、限流、越权拒绝 |

### 3.1 主用户流（演示脚本对齐）

1. 登录（演示账号，角色：合规员）
2. 新建案件 → 上传发票/装箱单等样张
3. 识别对照：左侧 PDF/图，右侧字段；高亮低置信度
4. 审查报告：顶部风险计数；点击一条展开「规则条款 + 原文定位」
5. 追问：「为什么判原产地风险？」→ 回答带引用
6. 审计看板：展示权限拒绝、密钥不落前端、提示注入拦截等日志条目

### 3.2 全局壳

- 顶栏：产品名「丝路智审」、当前案件面包屑、用户菜单（角色、退出）
- 侧栏：案件 / 上传 / 当前审查 / 审计（按角色显隐）
- 无营销 hero、无双 CTA「开始 / 了解更多」

## 4. 关键态（必须设计，禁止只做 happy path）

| 状态 | 表现 |
| --- | --- |
| Loading | 骨架对齐真实布局（双栏骨架），文案「正在识别单证…」；长任务可取消 |
| Empty | 案件列表空：说明 +「上传首份单证」一按钮 |
| Error | 说明原因与下一步（重试 / 重新上传）；不写「抱歉」堆砌 |
| Partial | OCR 部分失败：已出字段可编辑，失败页标红 |
| Denied | 越权：明确「当前角色无法查看审计」+ 联系管理员（演示用） |
| Offline / 降级 | 横幅：「云端 LLM 不可用，已切换本地规则引擎」；功能收缩说明 |

## 5. 文案语气

- 中文为主，关键术语可中英并列一次（如「原产地证 Certificate of Origin」）。
- CTA：上传单证 / 开始审查 / 保存更正 / 导出报告 / 继续追问。
- 风险文案写清「违反哪类规则」，不写恐吓或口号。
- 禁止：em dash 癖、Transform your workflow、假客户评价、假精确百分比。

## 6. 无障碍与演示约束

- 可见 `:focus-visible`；键盘可达主流程。
- 正文对比 AA；风险不只靠颜色，附文字标签（高/中/低/通过）。
- 触控目标 ≥44px（侧栏与主要按钮）。
- 现场真跑：界面不得暗示「演示数据」；样张用仓库内匿名样例文件名。
- 前端不存 API Key；错误信息不得回显密钥或内部堆栈。

## 7. anti-ai-ui 自检（本文件承诺）

| 检查 | 结论 |
| --- | --- |
| Inter/Geist？ | 否 → Noto Sans SC + IBM Plex |
| 紫/渐变？ | 否 → brand 青绿墨 |
| 奶油底/blob？ | 否 → 冷灰 canvas + 白纸 |
| Hero pill/三列图标卡？ | 否 → 工作台双栏 |
| 全面 fade-up？ | 否 |
| 灰正文？ | 否 → ink / ink-secondary |
