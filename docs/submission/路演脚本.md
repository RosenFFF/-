# 丝路智审 · 决赛路演脚本（10 分钟演示 + 5 分钟问答）

> 匿名陈述，只报参赛编号。全部核心功能现场真跑，禁止录屏与模拟数据。时间分配按评分权重：功能 30 / 模型优化 20 / 安全 25 / 创新 10 / 展演 15。

## 一、准备清单
- 演示机：所有镜像与本地模型已预拉、预热；`/readyz` 全绿。
- 三个账号：合规员、安全管理员、管理员（各自独立浏览器窗口）。
- 样例单证（脱敏自制）：①正常发票+装箱单；②金额不一致/HS 编码错误的问题单证；③藏有注入文本的单证；④多页报关单。
- 备用方案：手机热点；断网时走 L2 本地模型；L3 规则兜底。

## 三、5 分钟问答题库
**功能与场景**
1. 问：为什么选跨境单证？答：真实高频痛点，规则多语种多，且单证含商业秘密与个人信息，安全是刚需而非附加。
2. 问：现场用的数据是真的吗？答：单证为按真实格式自制的脱敏样例，识别、调用、审查全部现场实时运行，无预录结果；规则库来自公开渠道并标注出处。
3. 问：支持哪些单证和国家？答：发票、装箱单、原产地证、报关单；首批规则覆盖中国及若干一带一路/金砖国家公开规则（以规则库清单为准），可按国别扩展。
4. 问：识别错了怎么办？答：低置信度字段标黄，可人工修正后重审，全程留痕。
5. 问：和通用大模型直接问有什么区别？答：结构化抽取、确定性规则先判、条款约束引用、可审计；通用模型无法保证引用真实与数据不出域。

**模型与优化**
6. 问：用了哪几类模型？答：OCR、LLM、Embedding、Reranker 四类，调用记录可现场逐条核对。
7. 问：为什么 OCR 放本地？答：原件不出域、免费、断网可用，CPU 单页约 1–2 秒。
8. 问：如何抑制幻觉？答：规则引擎先判；LLM 只能引用检索到的 Top-5 条款，引用不在集合内即降级为需人工复核。
9. 问：为什么要重排？答：向量召回 Top-20 噪声大，重排后 Top-5 引用准确率提升（以消融数据为准）。
10. 问：怎么评测？答：自建脱敏评测集，测字段 F1、Recall@5、引用准确率、端到端时延，并做消融对比。
11. 问：多语种怎么做？答：BGE-M3 多语种检索 + LLM 按指定语言生成，界面中英 i18n。
12. 问：成本多少？答：只把脱敏文本送云端，向量与重排本地，单份审查成本很低（以实测为准）。
13. 问：主模型挂了怎么办？答：熔断后切通义千问，断网切本地 Qwen2.5-7B，再不行规则兜底，都真实运行。
14. 问：输出格式不稳定怎么办？答：JSON 模式 + Pydantic 校验，失败重试一次再降级。

**安全**
15. 问：数据会发给第三方吗？答：只发送脱敏后文本，人名电话账号等替换为占位符，映射只在任务内存，原件不出本地。
16. 问：脱敏漏了怎么办？答：输出侧再次检测敏感信息；脱敏规则有评测集持续回归；每次脱敏计数可审计。
17. 问：如何防提示注入？答：输入检测 + 数据区边界隔离 + 系统提示服务端固定 + 输出 Schema 校验，模型无任何工具权限，被拦截事件记审计。
18. 问：现场演示一下越权？答：合规员访问全局审计接口返回 403，管理员看板实时出现该事件。
19. 问：日志怎么防篡改？答：只追加，每条包含上一条哈希形成链，`/audit/verify` 可现场校验并定位断点。
20. 问：密钥放哪？答：只在服务端环境变量，不入仓、不下发前端，支持轮换；gitleaks 扫描全部 git 历史为零。
21. 问：租户隔离如何保证？答：PostgreSQL 行级安全，即使代码漏写过滤条件也查不到其他租户数据。
22. 问：做过代码扫描吗？答：Semgrep、Bandit、gitleaks、Trivy、pip-audit、npm audit 多工具自扫描，提交前 HIGH/CRITICAL 清零。
23. 问：依据了哪些标准？答：GB/T 45654-2025、GB 45438-2025（AIGC 标识）、GB/T 46796-2025、GB/T 22080-2025 / ISO/IEC 27001、ISO/IEC 23894、ISO/IEC 27701 等，安全说明书有逐项对照表。
24. 问：AIGC 标识怎么做？答：报告与回答显式标识，响应和导出文件含隐式元数据，按 GB 45438-2025。
25. 问：如何防刷与滥用？答：用户+IP 双维度限流、日 token 配额、单次 token 上限、熔断。

**落地与创新**
26. 问：最大创新是什么？答：安全内生且可现场验证，加上抗幻觉三道保险和原件高亮证据链。
27. 问：怎么落地？答：面向外贸中小企业与报关代理，私有化部署，按国别扩展规则库。
28. 问：规则更新怎么办？答：规则库带版本与生效日期，管理员更新后重建向量，入库审计。
29. 问：系统能完全替代人工吗？答：不能，定位为辅助决策，高风险与低置信项强制人工复核，符合 GB/T 45392-2025 对自动化决策的人工干预要求。
30. 问：下一步计划？答：语音问答、更多国家规则库、与单一窗口类系统对接。
