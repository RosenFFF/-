## 四、问答边界
- **是不是 BGE？** 当前是轻量检索/重排回退，不是 BGE 权重推理。
- **断网还能推理吗？** 本地 LLM 是设计档位；S 实测 Ollama 无模型，目前不能承诺 L2。可退规则或受控回放，明确不是模型推理。
- **追问稳定了吗？** 简短问题成功；宽泛问题失败未定位，不能作稳定性承诺。
- **有准确率和 P95 吗？** 尚未完成可复核评测，不报估算数字。
- **真实全栈了吗？** D 是 ASGI/inline；F 是开发服务器与替身数据库。生产浏览器 + 真模型 + 真 PG/Redis 的联合验证待补。
- **安全吗？** 有非 owner/FORCE RLS、启动门禁、脱敏和审计证据，不作绝对安全或标准认证承诺。
