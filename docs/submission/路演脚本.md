## 三、5 分钟问答题库
**功能与场景**
1. 问：为什么选跨境单证？答：真实高频痛点，规则多语种，且含商业秘密与个人信息，安全是刚需。
2. 问：现场数据是真的吗？答：单证为脱敏自制样例；识别、调用、审查按当前演示档位实时运行，无预录结果冒充；规则库来自公开渠道并标注出处。
3. 问：支持哪些单证和国家？答：发票、装箱单、原产地证、报关单；规则首批覆盖公开渠道国别清单，可扩展。
4. 问：识别错了怎么办？答：低置信度标黄，可人工修正后重审，全程留痕。
5. 问：和通用大模型直接问有何区别？答：结构化抽取、规则先判、条款约束引用、可审计；通用模型无法保证引用真实与数据最小化出域。

**模型与优化**
6. 问：用了哪几类模型？答：OCR、LLM、Embedding、Reranker（≥2 类硬性要求已满足），调用记录可核对。
7. 问：为什么 OCR 放本地？答：原件不出域、断网可用。
8. 问：如何抑制幻觉？答：规则先判；LLM 只能引用 Top-5 条款，否则降级人工复核。
9. 问：为什么要重排？答：召回 Top-20 噪声大，重排后 Top-5 更稳（以消融数据为准）。
10. 问：怎么评测？答：脱敏评测集测字段 F1、Recall@5、引用准确率、时延，并做消融。
11. 问：多语种怎么做？答：BGE-M3 检索 + LLM 按指定语言生成；界面中/英/越。
12. 问：成本？答：只送脱敏文本上云，向量与重排本地。
13. 问：主模型挂了怎么办？答：熔断切备用云端 → 本地 LLM → 规则兜底（见故障预案）。
14. 问：输出格式不稳怎么办？答：JSON 模式 + Pydantic，失败重试一次再降级。

**安全**
15. 问：数据会发给第三方吗？答：仅脱敏后文本；映射在任务内存；原件本地。
16. 问：脱敏漏了怎么办？答：输出侧再检；规则持续回归；计数可审计。
17. 问：如何防提示注入？答：输入检测 + 边界隔离 + 服务端系统提示 + Schema；无工具权限；记审计。
18. 问：演示越权？答：合规员访问全局审计 403，管理员看板出现该事件。
19. 问：日志防篡改？答：只追加哈希链，`/audit/verify` 可定位断点。
20. 问：密钥放哪？答：仅服务端环境变量，不入仓不下发；gitleaks 扫历史。
21. 问：租户隔离？答：应用层租户上下文 + PostgreSQL RLS 候选；即使漏写过滤也力求查不到外租户（以当轮验收档位为准）。
22. 问：做过代码扫描吗？答：Semgrep、Bandit、gitleaks、Trivy、pip-audit、npm audit；提交前 HIGH/CRITICAL 清零。
23. 问：依据哪些标准？答：GB/T 45654-2025、GB 45438-2025、GB/T 46796-2025、ISO/IEC 27001/23894/27701 等，说明书有对照表。
24. 问：AIGC 标识？答：显式标识 + 导出隐式元数据（按 GB 45438-2025）。
25. 问：如何防刷？答：用户+IP 限流、日 token 配额、单次上限、熔断。

**落地与创新**
26. 问：最大创新？答：安全内生可验证 + 抗幻觉三道保险 + 原件高亮证据链。
27. 问：怎么落地？答：外贸中小企业与报关代理，私有化，按国别扩规则。
28. 问：规则更新？答：版本与生效日期，管理员更新后重建向量，入库审计。
29. 问：能完全替代人工吗？答：不能，辅助决策；高风险与低置信强制人工复核。
30. 问：下一步？答：语音问答、更多国家规则库、与单一窗口对接；补齐真模型与演示环境验收指标。
