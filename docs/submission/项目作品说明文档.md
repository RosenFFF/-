# 丝路智审 · 项目作品说明文档

> BRICS2026-ST-143｜匿名技术稿 v0.4｜基线 main `aaee76a`。已验证不等于最终全栈验收。

## 1 目的与需求
面向跨境贸易单证复核，提供上传、OCR、结构化字段、规则与条款检索辅助审查、报告追问和审计。系统辅助人工判断，不提供法律合规认证；本次验证含合成发票和合成规则，不能外推真实业务准确率。

## 2 架构与数据流
React/TypeScript 界面 → FastAPI → OCR、LLM、规则/检索服务 → PostgreSQL、Redis、加密文件存储。接口契约见 `docs/api.yaml`，设计见 `docs/architecture.md`、`docs/design.md`。生产 Worker 是目标运行链路之一，本轮真实模型验证使用 ASGITransport、inline 后台任务，不是 ARQ worker 全链路彩排。

上传 → RapidOCR → 脱敏/注入检测 → DeepSeek 结构化抽取 → 规则与条款检索/重排 → LLM 审查 → 引用校验与 AI 标识 → 报告 → SSE 追问 → 审计。

## 4 可核对结果
以下仅引用 D 报告及 `realpath.json`，不作为性能承诺：
- 真实模型用例：1 passed in 9.93s。
- 上传/抽取 1347ms；审查 4923ms，6 条发现（2 rule、4 llm）、7 个引用。
- 简短追问 1285ms：1 delta、1 done、0 error，回放一致；审计 checked=16。
- 默认回归 391 passed、3 skipped；其中 DeepSeek opt-in 单独真实通过，默认测试仍含替身。
- S 恢复回归 388 passed、1 skipped，属于较早恢复阶段，不能与上述计数相加。

F 已合并，390 与 1440 宽度下真实后端代码（但 SQLite/fakeredis）和 mock E2E 均有归档。axe 与对比度结果按 F 原始记录解释。前端时延只引用 `run-*.json`，不在本文混写为生产性能。

## 5 安全与部署
非 owner 运行角色与 FORCE RLS、启动 catalog/grant 门禁、租户上下文、脱敏、审计链、限流、加密与输出控制的设计见《安全架构专项设计说明书》。S 证明服务仅回环监听；缺失目录成因未明、未保障开机自启，不宣称生产稳定性认证。密钥只由本机私有配置注入，禁止写入源码、文档、日志和 bundle。
