## 1 引言
### 1.1 编写目的
说明「丝路智审」的需求、设计、模型协同、模型优化、测试与部署，供评审核验作品与代码一致性。
### 1.2 背景
一带一路与金砖国家贸易规模持续增长，外贸中小企业需处理发票、装箱单、原产地证、报关单等多语种单证，涉及关税、原产地规则（如 RCEP、中国—东盟自贸协定）、禁限目录等大量规则。人工审核慢、易错，退单与滞港带来直接损失。
### 1.3 术语
OCR、LLM、RAG、Embedding、Reranker、HS 编码、原产地证、RLS、AIGC 标识、SSE。
### 1.4 参考资料
技术规程 §八 所列 GB/T 8567-2006、GB/T 15532-2008、ISO/IEC 25010:2011、GB/T 45654-2025、GB 45438-2025 等；本仓库 `docs/architecture.md`、`docs/design.md`、`docs/api.yaml`（OpenAPI **0.4.0**）。

## 3 概要设计
### 3.1 总体架构
前端（React/TypeScript 验单台）→ API（FastAPI）→ Worker（arq）→ 模型层（本地 OCR / Embedding / Reranker + 云端或本地 LLM）→ 数据层（PostgreSQL + 候选 RLS、Redis、加密文件卷）。
### 3.2 模块划分
`core`、`security`、`api/v1`、`services`、`ai`（ocr/llm/rag/prompts/guards）、`rules_engine`、`db`、`workers`、`audit`（详见 `docs/architecture.md`）。
### 3.3 接口设计
OpenAPI 3.1 契约 `docs/api.yaml` **info.version = 0.4.0**：统一错误（`code`）、异步 202 + 轮询、追问 SSE、审计与限流 429、`/audit/verify`。
### 3.4 数据设计
主要表：tenants、users、documents、ocr_results、document_fields、reviews、review_messages、rules、rule_chunks、model_calls、audit_logs。Alembic 迁移含租户 RLS **候选**策略；启动期 catalog/grant 漂移 gate fail-closed。

## 4 模型协同链路（≥2 类，本作品实际 ≥4 类设计）
| 序 | 模型类别 | 选型 | 部署 | 作用 | 代码状态 |
|---|---|---|---|---|---|
| 1 | OCR | RapidOCR（PP-OCRv4 ONNX） | 本地 CPU | 单证文字与坐标 | 管线已实现 |
| 2 | LLM | DeepSeek-V3（主）/通义千问（备）/Qwen2.5-7B Q4（离线） | 云端+本地 | 抽取、推理、追问 | 客户端与降级链已实现；**真调用 E2E 待演示环境/密钥** |
| 3 | Embedding | BGE-M3 | 本地 | 规则多语种检索 | RAG 检索路径已实现 |
| 4 | Reranker | bge-reranker-v2-m3 | 本地 | Top-20→Top-5 | 重排路径已实现 |

链路：上传 → OCR → 脱敏+注入检测 → LLM 抽取 → 规则引擎 → 向量召回 → 重排 → LLM 推理（仅可引用给定条款）→ 引用校验 + AIGC 标识 → 报告 → 追问。调用写入 `model_calls`。

**诚实边界**：M1/M2 代码侧主链路与安全已合并；**不得宣称**「真实云/Ollama LLM 现场 E2E 已验收」或「官方演示机环境已验收」。

## 5 模型优化设计
### 5.1 OCR 优化
预处理与低置信度复核标记；字段级准确率 **待补**。
### 5.2 LLM 提示与结构化
版本化提示、JSON 模式 + Pydantic、失败重试一次再降级；字段 F1 **待补**。
### 5.3 RAG 优化
条款级切片、重排、引用必须落在 Top-5；Recall@5 / 引用准确率 **待补**。
### 5.4 成本与时延
本地承担 OCR/向量/重排；云端仅脱敏文本；单份成本与 P95 **待补**。
### 5.5 鲁棒性
四级降级（L0 正常 / L1 备用云端 / L2 本地 LLM / L3 规则兜底）。现场切换以故障预案为准。
### 5.6 评测方法
自建脱敏评测集与消融表 **待补**（路演前填入）。

## 8 创新点
1. 面向一带一路/金砖的多语种跨境单证合规审查，贴合赛事主题。
2. 「规则引擎先判 + 条款约束 RAG + 引用校验」抗幻觉。
3. 点字段高亮原件证据链 + 模型调用可核对。
4. 安全内生：出域脱敏、哈希链审计可现场 `/audit/verify`、越权上看板。
5. 断网四级降级设计，配合故障预案可演示（真模型档位依赖环境就绪）。

## 9 应用价值
降低外贸中小企业退单与滞港风险；可按国别扩展规则库；数据最小化出域，满足保密要求。量化指标 **待补**。
